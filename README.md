# PayID Landing Page

Landing page de **PayID**, plataforma de identidad digital, documentos personales y pagos pensada para el Perú.

## Descripción

La página presenta la propuesta de valor de PayID:

- Documentos digitales: DNI, pasaporte, licencia, carné universitario y CONADIS.
- Recarga de transporte (Metropolitano y Línea 1) y alertas de saldo o vencimiento.
- Modo offline, perfiles familiares y asistente de trámites en el plan premium.
- Segmentos: estudiantes universitarios (18–29) y padres o tutores (25–45).
- i18n ES / EN.

El logo, las fotos y los videos quedan como espacios reservados hasta que el equipo los entregue.
